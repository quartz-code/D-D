# D-D — сборник заготовок для ведущих

Коллекция готовых цифровых штук для настольных ролевых игр: мини-игры, квесты,
сайты-артефакты, приложения-помощники и прочие приспособления, которые ведущий
(ДМ) может взять и принести за стол.

Смысл репозитория простой: **интересные идеи и возможности, собранные в одном
месте**. Не библиотека и не фреймворк — набор самостоятельных заготовок, каждую
из которых можно взять целиком, подправить под свою партию и играть.

## Как всё устроено

**Одна ветка — одна игра.** Ветка `main`, которую вы сейчас читаете, — это
только оглавление: кода в ней нет. Каждый проект живёт в собственной ветке,
ни с чем не перемешан и содержит всё своё: код, данные, свой README с быстрым
стартом и списком того, что нужно для запуска.

Поэтому «скачать игру» здесь означает «взять нужную ветку»:

```sh
# только одна игра, без остального содержимого репозитория
git clone -b <ветка> --single-branch https://github.com/quartz-code/D-D.git

# или, если репозиторий уже склонирован
git checkout <ветка>
```

## Какие заготовки сюда просятся

* квесты и головоломки, в которые играют прямо за терминалом или в браузере;
* сайты-артефакты: «найденный» архив организации, база данных гильдии,
  переписка НПС, газета игрового мира;
* НПС-собеседники на языковой модели — с характером, ограничениями и
  подтверждением важных событий ведущим;
* генераторы: имена, таверны, слухи, лут, случайные встречи;
* приложения-помощники ведущего: трекеры инициативы, счётчики ресурсов,
  панели состояния сцены.

## Как добавить свою заготовку

1. Создайте отдельную ветку от `main` — одна ветка на один проект.
2. Положите в неё всё необходимое и напишите README с быстрым стартом:
   что это, что нужно для запуска, как запустить, что правится под свою партию.
3. Добавьте строку в таблицу выше — оглавление живёт в `main`.

Пара привычек, которые экономят нервы:

* **Ключи и пароли не коммитим.** Их место — в локальном файле настроек или в
  переменных окружения, а в репозиторий кладём только образец конфигурации.
* **Если заготовка выполняет команды на машине игроков — играем в виртуальной
  машине.** Так случайное `rm` испортит партию, а не рабочий компьютер.
* **Материалы ведущего держим отдельно от игроков.** Шпаргалки с решениями,
  ответы к головоломкам и настройки ИИ — не в той папке, куда игроки полезут
  из терминала.
